# ACT11 — Investigación DHCP

## Portada

**Módulo:** 037 — Seguridad en servicios  
**Ciclo formativo:** ASIX  
**Alumno:** Deivid Cardona  

## Objetivo

Comprender el impacto del agotamiento del direccionamiento IP dinámico en una red local y aprender a proteger la infraestructura frente a ataques de DHCP Starvation.

## Contenido

1. Introducción
2. Preparación del entorno
3. Funcionamiento de DHCP
4. Ataque con Yersinia
5. Ataque con Scapy
6. Análisis con Wireshark
7. Mitigaciones
8. Preguntas
9. Conclusiones
